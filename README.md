# QuickPhoto

A thin iOS app for artists to practice timed sketching. Add your own reference photos, set a timer, and QuickPhoto shows them one at a time in random order.

## How it works

1. Add photos from your photo library.
2. Choose how long each photo stays on screen.
3. Start the session. When the timer runs out, another photo is picked at random and the countdown restarts.

Photos are shuffled so every one is shown once before any repeats.

## Building

Requires Xcode with the iOS 27 SDK.

1. Open `QuickPhoto.xcodeproj` in Xcode.
2. Select a simulator or a connected device.
3. Build and run.
